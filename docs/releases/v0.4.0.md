# OpenTypeless v0.4.0（Build 4）

发布日期：2026-10-09。支持 macOS 13.0+，安装包同时包含 Apple Silicon 和 Intel 架构。

## 新增功能

- **MAI Transcribe 2 Streaming**：说话时显示实时预览，停止录音后等待完整最终结果，再进入 AI 润色、粘贴和历史流程。
- **MAI Transcribe 2 非流式**：录音后上传完整音频，支持 Verbatim/Clean 转写风格、术语提示及音频历史保存。
- 两种 MAI 引擎均支持自动语言检测与语言提示。非流式默认共用 Azure Speech Key 和区域，也可使用独立配置。
- 明确显示连接、识别及等待最终文本的状态。连接错误、超时或取消时，不会将不完整预览当作最终结果插入。
- 包含此前尚未推送至 GitHub 主分支的 v0.3.0 Azure 最终精修、双阶段识别展示及精修降级行为。

## 配置

- 非流式：在「设置 → 语音」选择 MAI Transcribe 2，配置 Azure Speech Key 和支持的区域，或填写独立资源配置。
- 流式：选择 MAI Transcribe 2 Streaming，填写 Foundry 资源根地址、实际模型部署名称和该资源的 API Key。默认部署名称为 `mai-transcribe-2-streaming`。
- MAI 服务目前为公共预览，无 SLA；需要用户自己的 Azure 资源及凭据，并产生服务按量费用。安装包不包含任何用户 Key。

## 验证

- MAI 与 Azure Speech 精修离线回归测试通过。
- 真实 Azure 非流式四项测试、流式中英文两项测试通过。
- 本机 macOS 手动语音输入测试由用户确认通过。
- Workspace Debug/Release 构建通过，双架构 Release 的本地签名验证通过。

## 安装与升级

下载 `OpenTypeless.zip` 并解压，将 `OpenTypeless.app` 放入 `/Applications`。可使用附带的 `OpenTypeless.zip.sha256` 校验下载文件：

```bash
shasum -a 256 -c OpenTypeless.zip.sha256
```

本安装包使用本地 ad-hoc 签名，未进行 Apple 公证。如果 macOS 拦截首次打开，请按系统提示在「系统设置 → 隐私与安全性」允许打开。

替换 app 后，请在「系统设置 → 隐私与安全性 → 辅助功能」移除旧 OpenTypeless，重新添加 `/Applications/OpenTypeless.app` 并启用，再重启应用。否则语音识别可能成功，但无法自动插入到光标处。
